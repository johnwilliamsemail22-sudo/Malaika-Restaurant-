# Malaika Restaurant — delivery outcomes

## Experience and navigation
- [x] The site is a polished single-page experience for Malaika Restaurant on Silver Sand Road, Malindi, with a full-bleed atmosphere hero using the supplied `unnamed.webp` image.
- [x] Global Lenis smooth scroll provides weighted momentum while preserving touch behavior and a reduced-motion fallback.
- [x] The hero includes a rounded `See menu` CTA and a liquid-glass `Reserve a table` CTA; both preserve the editorial layout and remain touch-friendly.
- [x] The menu is a side-to-side snap-scroll carousel with larger centered dishes, a faded adjacent-slide peek, keyboard controls, and real-time background interpolation across the confirmed theme colors.

## Dish interaction and ordering
- [x] The visual language uses raw transparent food cutouts with soft ambient depth shadows and avoids card-grid presentation.
- [x] The pizza slide shows a wood-fired tomato-sauce base with real transparent Fresh Basil, Fior di Latte, and Extra Chilies cutouts. Topping controls sit with the pizza, trigger a spring-style drop animation, and update the WhatsApp order payload.
- [x] The burger slide has an interactive open/close stack reveal with ingredient labels plus pointer/touch parallax.
- [x] Dish names are visible and each dish has a bottom `Order now · price` WhatsApp action.
- [x] Menu content includes Seafood Salad (1,200 KSh), Lobster Ravioli (2,600 KSh), Grilled Octopus (2,400 KSh), Prawn Pasta with Cashewnut (2,200 KSh), Artisanal Gelato (600 KSh), and Classic Tiramisu (900 KSh).

## Reservation flow and copy
- [x] A reservation section at the bottom of the page collects name, date, time, guest count, and optional notes.
- [x] Submitting the reservation form opens WhatsApp with a structured, ready-to-send reservation message without losing page position.
- [x] Hero and intro copy avoid the old “served slowly” framing; the current positioning is “The coast, at its best.” with fire, tide, and good company setting the pace.
- [x] Body/UI use Geist-style sans typography and display headings use an editorial serif, with 600 interactive labels and 700 titles only.
- [x] The site is mobile-first and verified at 390px wide, with accessible labels, focus states, keyboard operation, performance-conscious motion, and reduced-motion support.
