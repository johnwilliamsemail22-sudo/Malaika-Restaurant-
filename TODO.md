# Malaika Restaurant — delivery outcomes

## Immersive structure and scroll engine
- [ ] The site is a polished single-page experience for Malaika Restaurant on Silver Sand Road, Malindi, with a full-bleed atmosphere hero using the supplied `unnamed.webp` image.
- [ ] Global Lenis smooth scroll provides weighted momentum while preserving touch behavior and a reduced-motion fallback.
- [ ] The menu is a side-to-side snap-scroll carousel where each dish occupies 100vw, adjacent dishes softly peek through, and keyboard controls provide equivalent navigation.
- [ ] The root background interpolates in real time across Linen Cream `#F9F8F6`, Ocean Turquoise `#0E4C5E`, Terracotta `#D96B43`, Vanilla Gelato `#FCF3CF`, and Twilight Indigo `#2C3E50` as the active meal changes.

## Dish interaction and menu content
- [ ] The visual language uses raw transparent food cutouts with soft ambient depth shadows and no cards, circles, borders, or stock-photo frames.
- [ ] The pizza slide shows a wood-fired tomato-sauce dough with Fresh Basil, Fior di Latte, and Extra Chilies controls; selections fall with a spring-physics style animation and update the live WhatsApp order payload.
- [ ] Burger and seafood slides respond to pointer/touch position with restrained layered scale and drift parallax.
- [ ] Menu content includes Seafood Salad (1,200 KSh), Lobster Ravioli (2,600 KSh), Grilled Octopus (2,400 KSh), Prawn Pasta with Cashewnut (2,200 KSh), Artisanal Gelato (600 KSh), and Classic Tiramisu (900 KSh).

## Type, conversion, and responsive quality
- [ ] Body/UI use Geist-style sans typography and display headings use an editorial serif, with 600 interactive labels and 700 titles only; secondary text is muted soft grey.
- [ ] Every menu slide has a 44px Rich Espresso / Dark Cocoa Brown `#3E2723` pill action with a Lucide chat icon that opens a pre-formatted WhatsApp order without losing page position.
- [ ] The design is mobile-first and verified at 390px wide, with accessible labels, focus states, keyboard operation, performance-conscious motion, and reduced-motion support.
- [ ] The site avoids gradient text, emojis, AI sparkle logos, stats bands, testimonial walls, and generic AI UI patterns.
